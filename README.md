UPI Transactions Analysis & Payment Failure Insights

📌 Project Overview

An exploratory data analysis project using Python and SQL to analyze UPI transactions, payment success rates, transaction amounts, and transaction trends.

🛠️ Tools & Technologies

Python

Pandas

Matplotlib & Seaborn

MySQL & MySQL Workbench

📂 Dataset

The dataset contains 1,000 transactions with details such as transaction timestamp, sender, receiver, amount, and status.

🔍 Analysis Performed

Cleaned and prepared transaction data using Python.

Analyzed successful and failed transactions using SQL.

Calculated transaction counts, success rates, and failure rates.

Examined average and total transaction amounts by status.

Analyzed daily and hourly transaction trends.

Identified top senders and receivers by transaction count.

Created visualizations to explore transaction patterns.

📊 Key Findings

Total Transactions: 1,000

Successful Transactions: 502 (50.20%)

Failed Transactions: 498 (49.80%)

Total Transaction Amount: ₹49,99,022.93

Average Transaction Amount: ₹4,999.02

The dataset has a high proportion of failed transactions. Further investigation would be needed to identify the causes because failure reasons are not included in the dataset.
